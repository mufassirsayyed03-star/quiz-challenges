🧠 Quiz App

A simple, interactive, and responsive Quiz Application built using HTML, CSS, and JavaScript. Create your own quizzes, add multiple-choice questions, select the correct answers, and test your knowledge with an interactive quiz interface.

✨ Features
📝 Add Quiz Questions — Create questions with four multiple-choice options.
✅ Correct Answer Validation — Specify and validate the correct answer.
🎯 Interactive Quiz — Select answers and get instant feedback.
🟢 Answer Indicators — Correct answers are highlighted in green, while incorrect selections are highlighted in red.
➡️ Next Question — Navigate through questions without reloading the page.
📊 Score Calculation — View your final score and percentage after completing the quiz.
🗑️ Delete Questions — Remove unwanted quizzes.
💾 Local Storage — Save quiz data in the browser.
📱 Responsive Design — Works on desktop, tablet, and mobile devices.
🎨 Modern UI — Clean interface with gradient backgrounds, cards, and interactive effects.
🛠️ Technologies Used
HTML5 — Application structure
CSS3 — Styling, animations, and responsive layout
JavaScript — Quiz logic, answer validation, and DOM manipulation
Local Storage — Persistent storage of quiz questions

🎮 How to Use
Open the Add Quiz page.
Enter a question and four answer options.
Enter the correct answer, matching one of the options.
Click Save Quiz to store the question.
Open the Play Quiz page.
Select an answer and view the feedback.
Click Next Question to continue.
Complete the quiz to see your final score.
💾 Data Storage

This project uses the browser's localStorage to store quiz questions.

Quiz data remains available after refreshing the page in the same browser and origin.
No database or backend server is required.
Data is not automatically shared across different browsers or devices.
Clearing the browser's local storage may remove saved quizzes.
